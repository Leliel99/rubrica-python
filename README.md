# Rubrica Python

Una rubrica da terminale scritta in Python che permette di gestire i contatti.

## Funzionalità

- Aggiungere contatti (nome e numero di telefono, per ora)
- Cercare un contatto per nome o per numero
- Modificare nome o numero di un contatto esistente
- Eliminare un contatto
- Mostrare tutti i contatti in ordine alfabetico
- Salvataggio automatico su file JSON

## Come si usa

'''bash
python3 Rubrica.py
'''

# Tecnologie

- Python 3
- Modulo json (libreria standard)
